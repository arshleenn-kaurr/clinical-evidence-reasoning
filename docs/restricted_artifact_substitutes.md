# Restricted-artifact substitute strategy

For every `LICENSE_REVIEW` group in `docs/licensing_decision_matrix.md`, what the public release already ships (or could ship) **in place of** the restricted file, so the public repo stays as informative as possible without redistributing content under review. No transformed copy of any restricted file is proposed anywhere below — every substitute is either already-public derived data, a hash, a schema, or a genuinely new project-authored artifact.

## What is deliberately NOT proposed

- **No transformation, redaction, or paraphrase of any restricted file.** "Redacting" Cochrane/AHA text to make it "safe" is not a substitute this document proposes, because partial redaction of copyrighted or licensed text does not resolve a redistribution question — it just makes the question harder to evaluate. The substitutes above are either independently-public derived data (computed over, not copied from, the restricted content) or genuinely new content.
- **No synthetic "lookalike" cohort** generated by paraphrasing or perturbing the real cohort. That would still be a derivative work of the restricted source and would not actually resolve anything.

## How this fits the public release

Every substitute row marked "already public today" is already shipped in `dist/public_release_preview/` (verify with `python scripts/validate_public_release.py`, step 5). The "possible additional substitute" column is a worklist for Phase 5B, contingent on which `LICENSE_REVIEW` groups the authors decide not to clear.
