# Licensing decision matrix

Narrative companion to [`licensing_decision_matrix.csv`](licensing_decision_matrix.csv) (generated by `scripts/build_licensing_decision_matrix.py` from the 64 `LICENSE_REVIEW` rows in `docs/public_release_manifest_draft.csv`). **No legal conclusions are made here.** Every flag below is a factual provenance observation (already documented in `docs/public_release_audit.md` / `docs/data_provenance.md`), not a licensing determination. Where a redistribution question is open, this uses "requires redistribution-rights review," never "illegal to publish."

## Scope

All 64 files are inside `historical_package/` across the three accepted-paper packages (static, Gemini persistent, Gemini aligned control). None have been reclassified; this matrix explains the existing classification, it does not change it.

## Groups (7 artifact types, 64 files)

| Artifact type | Files | Upstream | Disposition(s) |
|---|---|---|---|
| `model_output` | 32 | Gemini / GPT-OSS-120B (Groq) provider responses | `UNKNOWN` |
| `derived_analysis_table` | 9 | `score_results.py` joins of cohort + model output | `RELEASE_DERIVED_ONLY` |
| `frozen_cohort` | 7 | MEDAL/Cochrane + MEDAL/AHA, anonymized/audited/frozen | `UNKNOWN` |
| `candidate_audit_csv` | 7 | MEDAL/Cochrane or MEDAL/AHA + author audit fields | `UNKNOWN` |

### `model_output` (32 files) — `UNKNOWN`

Every `results/*.jsonl` across all three packages: canonical results, attempt logs, dev/smoke runs, checkpoints, and backups. Two independent open questions, not one:

1. **Provider terms.** Google's (Gemini) and Groq's terms of service for redistributing model outputs were not reviewed as part of this repository's work.
2. **Content inheritance.** Model rationale text may restate or closely paraphrase the cohort's anchor/question text, which is itself under review (see `frozen_cohort` below).

**Public-release value is uneven within this group**: the canonical accepted-paper files (`final_main_gemini_3_6_flash.jsonl`, `replication_gemini_3_6_flash_CLEAN.jsonl`, `gemini_260_results.jsonl`, `aligned_control_results.jsonl`, etc.) are high-value — they are the scientific record itself. Dev/smoke/checkpoint/backup variants (`dev_gemini_2_5_flash.jsonl`, `*_checkpoint_*`, `*_FINAL_BACKUP`, `*_PRE_RESUME_BACKUP`) are lower-value duplicates or operational artifacts already separately flagged `ARCHIVAL_ONLY`-adjacent in `docs/public_artifact_plan.md`.

### `derived_analysis_table` (9 files) — `RELEASE_DERIVED_ONLY`

`analysis/*/merged_scored_results.csv` in every static cohort. This is the one group with a confident, actionable disposition: the per-cohort aggregate CSVs that score_results.py also produces (`accuracy_by_condition.csv`, `evidence_dilution_rate.csv`, `order_sensitivity.csv`, `veto_failure_rate.csv`, `aligned_control.csv`, `confidence_shift.csv`, `flip_threshold.csv`) are **already public** (`PUBLIC_OPTIONAL`) and carry every reported statistic without per-row case text or rationale. No further action needed; this group can simply stay archive-only.

### `frozen_cohort` (7 files) — `UNKNOWN`, highest priority

`dev_cases.jsonl`, `final_main_cases.jsonl`, `final_veto_cases.jsonl`, `replication_cases.jsonl` (static), plus the byte-identical copies `dev_cases.jsonl` / `replication_cases_verified.jsonl` (Gemini persistent) and `aligned_control_cases_40.jsonl` (aligned control — a 40-line subset of the 260 cohort). Questions are anonymized ("Intervention A/B"), but anchor text paraphrases Cochrane/AHA findings, sometimes including reported effect estimates.

**This is the single highest-value, highest-priority item to clear.** Every result in `docs/result_provenance.csv` traces back to these case files; resolving this question (and only this one) would substantially increase what can move from `UNKNOWN` to `PUBLIC_IF_CLEARED` elsewhere, since `generated_prompt` resolves automatically once this does.

### `candidate_audit_csv` (7 files) — `UNKNOWN`

`cochrane_candidates.csv` (+ `.pre_audit`, `_audited` variants), `replication_candidates.csv` (+ `_audited`), `aha_veto_candidates.csv`, `latent_v2_anchor_audit.csv`. Pre-freeze audit CSVs with author-added columns (`eligible`, `audit_note`, anonymized fields) alongside the original MEDAL source notes. Same review as the raw sources; the audit-only columns alone (without the Cochrane/AHA notes column) could become a `RELEASE_DERIVED_ONLY` substitute if the raw text stays restricted — see `docs/restricted_artifact_substitutes.md`.

### `generated_prompt` (6 files) — `UNKNOWN`, resolves with `frozen_cohort`

`*_prompts.jsonl` across all 6 static cohorts plus `dev_prompts.jsonl`. The template (`prompt_template.md`) and the synthetic lower-tier evidence-card construction are project-authored and already public; what's restricted is the embedded cohort anchor/question text. No independent review needed — this group's status is a direct function of the `frozen_cohort` decision.

### `raw_source_dataset` (2 files) — `UNKNOWN`

`QA-systematic-review.jsonl` (raw MEDAL Cochrane QA export) and `recommendation-aha-guideline-clean.jsonl` (raw MEDAL AHA export). The MEDAL dataset's own license/terms of use were not located during recovery; Cochrane's and AHA's underlying terms are a second, separate question.

### `illustrative_example` (1 file) — `RELEASE_RECONSTRUCTION_SCRIPT_ONLY`

`example_audited_case.jsonl`. A single real Cochrane-derived record, used nowhere in any pipeline. Lowest stakes, clearest resolution: if a worked example is wanted for public documentation, author a **new** synthetic record with the same field shape rather than attempt to clear or transform this one. See `docs/restricted_artifact_substitutes.md`.
