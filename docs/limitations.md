# Limitations

## SCIENTIFIC LIMITATIONS (from the historical protocols; see them for full text — not rewritten here)
- Synthetic lower-tier cards are controlled perturbations, not real studies. The benchmark tests evidence-composition robustness, not prospective clinical decision quality (`analysis_contract.md`).
- Persistent-context differences are "persistent-context update sensitivity", not anchoring, calibrated uncertainty, latent belief, or a pure causal effect of evidence arrival (`PROTOCOL_FREEZE_GEMINI.md`).
- The aligned control is post-hoc and "does not establish a unique causal mechanism" (`PROTOCOL_FREEZE_ALIGNED_CONTROL.md`).
- Confidence is self-reported; `dominant_evidence_ids` is reported attribution, not evidence of causal use.
- The static Gemini runs sent temperature=0. The persistent Gemini runs sent no sampling parameters (current API deprecates them). This API-era difference is disclosed in the Gemini protocol.
- GPT-OSS static runs are a post-hoc second-model sensitivity on the same cases. Veto results are the same 15 cases under two models, not 30 independent cases.

## ARTIFACT / PROVENANCE LIMITATIONS

1. **`posthoc_contrasts.py` historical script-hash mismatch.** The archived post-hoc analysis manifest records an earlier script hash that is no longer available (`script_sha256 f388eb83…`). The recovered script hashes to `c4fd856b…` — it differs from that recorded hash — but regenerates all archived post-hoc outputs byte-for-byte under the verified reproduction environment (SciPy 1.16.3). No other version exists anywhere searched. The historical code change cannot be reconstructed and is retained as a provenance limitation. **Not "fixed."** See `docs/posthoc_hash_investigation.md`.
2. **Original Figure 1 plotting code not recovered.** Its numerical data was reproduced exactly in Phase 3. A NEW, clearly labeled reconstruction (`scripts/reconstructed/plot_genai4health_figure1.py`, status `DATA_EXACT / PLOT_RECONSTRUCTED`) redraws the panels from that reproduced data. See `docs/figure1_reconstruction.md`.
3. **Original `canonical_results_reference.md` generator not recovered.** A NEW, clearly labeled reconstruction (`scripts/reconstructed/build_canonical_results_reference.py`) regenerates it — verified **byte-identical** to the archive (same sha256). The row order used in 3 of its 7 sections could not be derived from any recovered manifest and was read off the archived text as a presentation choice (not a computed value). See `docs/canonical_reference_reconstruction.md`.
4. **Historical numpy/pandas/scipy versions are unknown.** `.pyc` evidence places the static package's execution at CPython 3.14 (case prep once at 3.10) and the AgenticLS packages at CPython 3.13 — none of which matches the Phase 4 pinned reproduction environment (Python 3.12 / scipy 1.16.3), which is a verified-reproducing environment, not a claim about history. See `docs/reproduction_environment.md` / `docs/environment_validation.md`.
5. **Static Gemini primary and veto runs have no separate attempt log.** Any transient failures during those two runs (if there were any) are unrecorded; only the successful canonical rows survive.
6. **Camera-ready manuscripts are pending.** Both accepted papers are marked `CAMERA-READY PENDING` throughout this repository. `docs/result_provenance.csv` reserves (currently `TODO`) `camera_ready_location` / `table_number` / `figure_number` / `section` fields for when the final PDFs are available; nothing is guessed in the meantime.
7. **Data / provider-output redistribution rights are pending review.** Raw MEDAL Cochrane and AHA guideline text, every cohort/prompt file built from it, and model outputs that may restate it are classified `LICENSE_REVIEW` or `NEEDS_LICENSE_REVIEW`, not cleared for release. See `docs/public_release_audit.md`, `docs/public_artifact_plan.md`, `docs/public_release_manifest_draft.csv`.
