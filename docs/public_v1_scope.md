# Public v1 release scope

A deliberately smaller, professional first public release carved out of the 341 files currently eligible to be public (`PUBLIC_CORE` + `PUBLIC_OPTIONAL` in `docs/public_release_manifest_draft.csv`). Generated by `scripts/build_public_v1_scope.py` into [`public_v1_scope.csv`](public_v1_scope.csv) (source of truth for `scripts/build_public_release.py --v1-core`). **Nothing is deleted from the archival repo either way** — `DEFER_FROM_V1` means "not in the first public release," not "never public."

| Scope | Count | Meaning |
|---|---|---|
| `V1_CORE` | 183 | Root docs, protocols, frozen runners/analysis code, reported analysis outputs, experiment manifests, reproduction/release tooling, CI, public-safe tests. |
| `V1_SUPPORTING` | 43 | Real provenance detail, secondary to the main narrative: phase audit reports, compact reproduction-evidence summaries, registries, small execution-order logs. |
| `DEFER_FROM_V1` | 115 | Clutter for a first-time reader: redundant analysis-reproduction intermediates, stale operational logs, dev/smoke-only output, superseded latent-v1 code, internal migration bookkeeping, not-yet-implemented placeholders. |

- Root: `README.md`, `CITATION.cff`, `LICENSE`, `pyproject.toml`, `.python-version`, `requirements*.txt`, `.gitignore`, `.github/workflows/reproducibility.yml`.
- Every `papers/*/README.md`, `reproduce.md`, `paper/README.md`.
- Every `experiments/*/README.md` and `experiment_manifest.json` (navigation + machine-readable provenance).
- The three packages' frozen protocols and freeze manifests (`README.md`, `analysis_contract.md`, `audit_protocol.md`, `PROTOCOL_FREEZE_GEMINI.md`, `PROTOCOL_FREEZE_ALIGNED_CONTROL.md`, every `.sha256` lock, `freeze_manifest.json`, `replication_freeze_manifest.json`, `CONTROL_FREEZE_MANIFEST.json`, `SHA256SUMS.txt` ×3).
- Every frozen runner and analysis script actually used by a reported result (`run_gemini.py`, `run_groq.py`, `make_conditions.py`, `score_results.py`, `posthoc_contrasts.py`, `make_latent_v2.py`, `prepare_cases.py`, `prepare_replication_candidates.py`, `freeze_cases.py`, `freeze_split.py`, `freeze_replication.py`, `run_sequential_gemini.py`, `analyze_sequential_gemini.py`, `run_aligned_control_gemini.py`, `analyze_aligned_control.py`, `validate_smoke.py`, `validate_aligned_control.py`).
- Every reported analysis output: the per-cohort scoring CSVs for primary/replication/veto/gpt_oss_primary/gpt_oss_veto/latent_v2 (not `dev_*`), all of `analysis/posthoc_contrasts/`, `canonical_results_reference.md`, Figure 1 (`.pdf`/`.png`), `gemini_260_analysis.json`, `aligned_control_analysis.json`.
- All reproduction/release tooling: `scripts/*.py` (both Level-1 and Level-2 — shown as what makes the archive-vs-public distinction real, not just claimed) and `scripts/reconstructed/*.py`.
- The full `tests/` suite (public-safe and archive-only — the split itself is part of what makes the reproducibility claims checkable).
- The documentation that explains all of the above: `docs/limitations.md`, `reproducibility.md`, `reproducibility_levels.md`, `reproduction_environment.md`, `methodology.md`, `data_provenance.md`, `result_provenance.md`/`.csv`, `public_dependency_audit.md`, `public_release_audit.md`, `public_artifact_plan.md`, `posthoc_hash_investigation.md`, `figure1_reconstruction.md`, `figure_reproduction_status.md`, `canonical_reference_reconstruction.md`, `public_release_manifest_draft.csv`, and this phase's new docs (`licensing_decision_matrix.*`, `restricted_artifact_substitutes.md`, `license_options.md`, `public_v1_scope.*`, `github_release_metadata.md`, `release_strategy.md`, `archival_plan.md`, `final_release_checklist.md`, `camera_ready_provenance_mapping_template.csv`, `THIRD_PARTY_NOTICES.md`, `DATA_AND_ARTIFACT_RIGHTS.md`).

## V1_SUPPORTING (43 files) — keep, but secondary

Phase audit/progress reports (`hash_verification_report.md`, `canonical_structure_report.md`, `genai4health_prespecified_reproduction.md`, `environment_validation.md`, `phase3_reproduction_report.md`, `phase4_release_readiness_report.md`, `phase4_1_public_validation_report.md`, `recovery_status.md`); compact machine-readable reproduction evidence (`validation/hash_verification_report.json`, `canonical_structure_report.json`, the comparison JSONs, `validation/diffs/`, the reconstructed-figure/reference *outputs* themselves); small execution-order logs (`*_terminal.log`, which document the reported 130/130 and 5/5 arm-order balances); data/artifacts registries and READMEs; and the Groq extension's own navigational docs (kept visible specifically so the "not part of either accepted paper" boundary stays clear to a public reader, even though deferred from the core narrative).
